<a id="optional-endbot-ui-resource-pack"></a>
# 任意の Endbot UI リソースパック

*Endbot UI* は、自分の端末に入れる任意のリソースパックです。ゲーム内のメニューを大きくし、スクリプトのエディターに複数行の欄を加えます。パックがなくても、スクリプト全体を 1 つの欄で編集すること以外は、Endbot のすべての機能が使えます。

<a id="what-it-changes"></a>
## 変わること

| 変更 | 場所 |
| --- | --- |
| フォームのウィンドウが大きくなります。画面から余白を引いた大きさで、最大 420×300 UI 単位です (通常は 225×200) | すべてのサーバーのフォーム |
| ボタンが小さくなります。高さ 24 単位 (通常は 32) なので、メニューのスクロールが減ります | ボタンのあるすべてのメニュー |
| 縦に長い複数行の欄になります。Enter で改行が入り、欄はスクロールし、32768 文字まで入ります | 下に挙げた Endbot のスクリプトの欄だけ |

パックが有効な間は、大きなウィンドウと小さなボタンが Endbot だけでなく **すべての** サーバーのフォームに適用されます。

複数行になるスクリプトの欄:

| 欄 | パックがあるとき |
| --- | --- |
| 行のエディターの **全体をまとめて編集 (UIパック)...** | スクリプト全体を 1 つの欄で編集できます。オペレーターが `ui-pack-editor` をオンにしたときだけ表示されます。 |
| **新しいスクリプト** のテンプレートの欄 | スクリプトを作る前に、全体を書けます。これにも `ui-pack-editor` が必要です。 |
| **下に行を追加** と **新しい行** (先頭または末尾に追加) | 貼り付けたまとまりの行がそのまま保たれます。 |

複数行の欄からの保存も、ほかの保存と同じチェックを通ります。変更なしで返された内容は、新しいリビジョンを保存せずにエディターに戻ります。

<a id="install"></a>
## インストール

パックは自分の端末にだけ入れます。サーバーにパックは要りません。

1. [GitHub のリリース](https://github.com/amatouhake/endbot/releases)から `endbot-ui-<pack version>.mcpack` をダウンロードします。各リリースに添付されていて、ほかの配布場所はありません。バージョンはパック自身のもので、Endbot のバージョンとは別です。
2. Windows では `.mcpack` ファイルを開きます。Minecraft が取り込みます。
3. **設定 → グローバルリソース** で *Endbot UI* を有効にします。2 行の説明と、抽象的な E のアイコンで表示されます。
4. **全体をまとめて編集** と、複数行の **新しいスクリプト** の欄を使うには、オペレーターに `ui-pack-editor` をオンにしてもらいます ([オペレーター向け](#for-operators)を参照)。

モバイルのクライアントも、同じように `.mcpack` ファイルを取り込めます。コンソール機では自分でグローバルパックを追加できないので、このパックは実質的に PC とモバイルのプレイヤー向けです。

<a id="using-the-multi-line-field"></a>
## 複数行の欄を使う

- **入力を始めるには、欄の枠を 1 回クリックします。** 文字の上をクリックしてもカーソルは出ません。その後は欄全体を編集でき、マウスホイールでスクロールし、表示がカーソルを追いかけます。
- 改行、日本語の文字、`§` コード、タブ、行末の空白は、保存しても保たれます。

<a id="without-the-pack"></a>
## パックがないとき

| 機能 | パックがないとき |
| --- | --- |
| メニュー | 通常の大きさです |
| **下に行を追加**、**新しい行** | これまでどおり、1 行ずつ使えます |
| **全体をまとめて編集** | 使えません。欄には最初の数行しか表示されず、入力しても何も起きず、約 100 文字で入力が止まります。行のボタンか、本と羽根ペンを使ってください。 |
| **新しいスクリプト** | テンプレートは欄の上にラベルとして表示されます。**表示どおりに保存 (UI パックなし)** をオンにすると、そのまま保存できます (欄を空にはできません)。保存した後で行を編集してください。 |

パックなしで **全体をまとめて編集** を使うと、複数行のスクリプトの保存は **拒否され、保存されません**。改行が失われたというメッセージが出ます。スクリプトは変わりません。**新しいスクリプト** の欄も同じです。1 行のスクリプトやテンプレートは 1 行のままで構いません。

[ウェブのエディター](../WEB_DEPLOY.md)はパックなしで使え、構文の色分け、補完、差分の表示がある本格的な作成ツールです。

<a id="remove-it"></a>
## 取り除く

**設定 → グローバルリソース** で *Endbot UI* を無効にします。サーバー側は何も変わりません。

<a id="for-operators"></a>
## オペレーター向け

プラグインの `config.toml` (管理されたインスタンスでは `endbot.toml`) の `[scripting]` でエディターをオンにし、再起動します:

```toml
[scripting]
ui-pack-editor = true
```

- 既定ではオフです。プレイヤーがパックを入れる場合だけオンにしてください。パックを使うコントローラーがいないときは、オフのままにします。
- パックのないプレイヤーにも **全体をまとめて編集** は表示されます。使おうとすると、行のボタンか本を使うよう案内されます。新しいスクリプトの画面では、**表示どおりに保存** をオンにして、保存した後で行を編集するよう案内されます。
- サーバーのパックの一覧は空のままにしてください。`world_resource_packs.json` も `texturepacks-required` も使わず、`server.properties` にも何も設定しません。同じファイルをサーバーのリソースパックとして配る使い方は、検証していません。

<a id="known-limits"></a>
## 既知の制限

- **実績:** このパックはリソースだけのもので、サーバーにもワールドにも触れません。リソースパックが実績を無効にするとは知られていません。ただ、パックを有効にした状態での実績の解除はまだ観測していないので、このパックが実績に対して安全だとは言っていません ([#277](https://github.com/amatouhake/endbot/issues/277)、[ACHIEVEMENTS.md](../ACHIEVEMENTS.md))。
- **モバイル:** 複数行の欄は、モバイルのクライアントではまだ試していません ([#277](https://github.com/amatouhake/endbot/issues/277))。
- **クライアントの更新:** このパックは、非公式なクライアントの UI の内部に頼っています。Minecraft の更新の後に適用されなくなることがあり、そのときはフォームが通常の見た目に戻ります。サーバー側は何も壊れません。
- **ほかのサーバー:** パックが有効な間は、ほかのサーバーのフォームも大きなウィンドウと小さなボタンになります。

実際のクライアントで確認したこと: [検証の状況](../COMPATIBILITY.md#validation-status)。パックのしくみとビルド: [ui-pack/README.md](../../ui-pack/README.md)。
