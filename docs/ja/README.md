# Endbot プレイヤー向けガイド

Endbot は、Minecraft 統合版 (Bedrock) の公式サーバーに Bot を追加します。Bot はゲーム内のコマンドやメニュー、ウェブから操作できるプレイヤーです。

ここにあるのは、サーバーのオペレーターから権限をもらった人向けの文書です。サーバーのマシンに触れる必要はありません。英語版が原文で、このディレクトリはその翻訳です。

| 文書 | 内容 |
| --- | --- |
| [はじめての Endbot](GETTING_STARTED.md) | 5 分で最初の Bot を出し、いくつか試してみる |
| [コマンド](COMMANDS.md) | `/bot`、`/botgroup`、`/botscript`、`/botweb` のすべての操作、メニュー、返事の意味 |
| [グループ](GROUPS.md) | 何体もの Bot を 1 つの対象として操作する |
| [スクリプトのチュートリアル](SCRIPTING_TUTORIAL.md) | 最初のスクリプトからイベントへの反応まで |
| [スクリプトのリファレンス](SCRIPTING.md) | 書き方、Luau API、監視、トリガー、実行の寿命 |
| [UI リソースパック](UI_PACK.md) | メニューを大きくし、複数行のエディターを使えるようにする任意のクライアント用パック |

役割 (コントローラー、スクリプター) と、だれがだれの Bot を使えるかは [PERMISSIONS.md](../PERMISSIONS.md) (英語) にあります。ウェブへのサインインは、ゲーム内で `/botweb link` を入力するところから始まります。

ゲームの言語を日本語にしていれば、ゲーム内の返事、ヘルプ、メニューは日本語で表示されます。コマンドはどの言語でも同じです。
